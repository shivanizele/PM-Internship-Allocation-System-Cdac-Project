# InternConnect: Smart Internship Allocation System

A web-based application designed to automate, streamline, and optimize the process of matching students with suitable internship opportunities under the PM Internship Scheme. 
The system leverages candidate profiles, skills, qualifications, location preferences, and sector interests to ensure an efficient, fair, and transparent allocation process.

## 🚀 Objectives
* **Automated Matching:** Streamline the internship allocation and matching workflow.
* **Intelligent Recommendations:** Recommend the most relevant internship roles based on student profiles and skills.
* **Enhanced Efficiency:** Significantly reduce manual processing time and operational overhead.
* **Transparency & Fairness:** Ensure a fair merit- and preference-based allocation process.
* **Analytics & Insights:** Provide interactive dashboards and reports for monitoring and analyzing allocation metrics.

## 🛠️ Tech Stack

### Frontend
* **JavaScript** (React.js / Core JS)
* **HTML5 & CSS3**

### Backend
* **Java** (Spring Boot / Enterprise Java)
* **Database:**  MySql

## 📌 Scope & Key Features
* **Student Module:** Secure registration, detailed profile management, and application tracking.
* **Resume Parsing:** Resume upload capabilities paired with automated skill extraction.
* **Industry Portal:** Comprehensive internship posting and tracking management for corporate partners.
* **Matching Engine:** Advanced candidate recommendation and ranking system.
* **Admin Dashboard:** Centralized reporting, metrics visualization, and system monitoring.

## 🔮 Future Scope
* Seamless integration with the official PM Internship Portal.
* Native mobile application support for on-the-go accessibility.
* Real-time recommendation system upgrades.
* Advanced analytics powered by predictive reporting models.

## 💻 Getting Started

### Prerequisites

* **Java JDK** (v17 or higher recommended)
* **Node.js** & **npm**
* **Maven** (for backend dependencies)

### Backend Setup

1. Navigate to the backend directory:
```bash
cd Cdac_Project-Backend

2. Build the project using Maven:
```bash
mvn clean install

3. Run the application:
```bash
mvn spring-boot:run

### Frontend Setup

1. Navigate to the frontend directory:
```bash
cd pm-internship-frontend

2. Install the necessary dependencies:
```bash
npm install

3. Start the local development server:
```bash
npm start
